# 📝 Notes App

A full-stack Notes App built with **React**, **Node.js**, **Express**, and **MongoDB Atlas**.  
Features include authentication, role-based access, CRUD notes, dark mode toggle, and responsive layout.

---

## 🚀 Live Demo

- **Frontend:** [https://notes-frontend.netlify.app](https://notes-frontend.netlify.app)
- **Backend API:** [https://notes-backend.onrender.com](https://notes-backend.onrender.com)

---

## ✨ Features

- 🔐 JWT Authentication (Signup/Login)
- 👤 User Profile Display
- 📝 Create, Edit, Delete Notes
- 📌 Pin/Unpin Notes
- 🌗 Dark Mode Toggle
- 📱 Responsive Grid Layout
- 🛡️ Admin Dashboard (Role-Based Access)

---

## 🛠️ Tech Stack

| Layer      | Tech Used                          |
|------------|------------------------------------|
| Frontend   | React, Material-UI, Axios, Toastify |
| Backend    | Node.js, Express, MongoDB, Mongoose |
| Auth       | JWT, Role-Based Middleware         |
| Deployment | Netlify (frontend), Render (backend) |
